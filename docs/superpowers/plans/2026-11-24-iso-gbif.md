# `iso` on GBIF's country areas — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the `iso` gazetteer from scratch. Countries become GBIF's areas, as a land shape and an opt-in land + EEZ shape under the same ids. Subdivisions come mostly from OSM, fitted into those countries without losing ids.

**Architecture:** A new `scripts/iso/` package. Each source gets its own module, and the modules share types from `model.py`. The build runs in this order:
1. GBIF's union rows, with GBIF's changes replayed;
2. per-code country shapes;
3. the id universe from the committed `labels.tsv` and Wikidata;
4. shape candidates per subdivision;
5. fitting;
6. writing the tree and checking its invariants.

The build refuses to write a tree that fails a check. When it fails, `rebuild.sh` restores the committed tree.

**Tech Stack:** Python 3.13, shapely 2.2, GDAL `ogr2ogr`, `osm2geojson`, the repo's `common/` helpers (`download`, `overpass.fetch`, `wikidata.sparql_csv`, `labels.write_labels`, `manifest.write_manifest`). Tests are plain scripts (`python scripts/test_*.py`, functions named `test_*`, no framework), as in `scripts/test_wikidata.py`.

**Spec:** `docs/superpowers/specs/2026-11-24-iso-gbif-design.md`

## Global Constraints

- Ids are never fewer than in the last committed `iso/labels.tsv`, which is the floor. New ids only from Wikidata `P300`, matching `^[A-Z]{2}(-[A-Z0-9]{1,6})?$`.
- GBIF files: `EEZ_land_union_v4_202410.zip` and `eez_v12.gpkg`.
  - GBIF's mirror: `https://download.gbif.org/MapDataMirror/2026/10/`, reachable only from GBIF's network.
  - CI copy: release `gbif-mapdatamirror-2026-10` of the private repo `CatalogueOfLife/gazetteer-sources`.
- GBIF's changes are replayed from `import_political()` of `gbif/geocode` `database/import.sh` at commit `6a578ecefde0`.
- A row counts for every code among `iso_ter1..3`. Alpha-3 maps to alpha-2 through `https://api.gbif.org/v1/enumeration/country`, plus `XKX`→`XK`.
- Fitting keeps a source's shape when at least 10% of it survives (`MIN_KEEP = 0.10`).
- Douglas–Peucker at 0.005° is applied only when writing. Coordinates are rounded to 6 decimals.
- Feature properties are `iso_id`, `iso_name`, `name` and `source`, as today. Symlinks are relative (`FR-PM.geojson -> PM.geojson`).
- Layout: `iso/features/` holds the land shapes and `iso/eez/features/` the land + EEZ shapes. One `labels.tsv`, `sources.tsv` and `build.json` serve both.
- Commits: no mention of Claude and no AI trailers (from `~/.claude/CLAUDE.md`). The main `README.md` stays light; the gazetteer's story goes in `iso/README.md`.
- Never read or print `scripts/common/download.py`, `overpass.py` or `wikidata.py`, because they hold a contact address. Use them only through the call shapes given here.

## Review Focus

1. **An Overpass or Wikidata fetch fails for one country.** The build must fail rather than write circles. Test: `test_osm_fetch_failure_fails_the_build` (Task 5).
2. **`iso/labels.tsv` is missing or nearly empty** (a fresh wipe, a bad checkout). The build must refuse to run instead of shrinking the floor. Test: `test_floor_refuses_missing_or_small_file` (Task 4).
3. **Shapes crossing the antimeridian** (Fiji, Chukotka, Kiribati from OSM). They must clip like any other, not turn into conflicts. Test: `test_unwrap_antimeridian` (Task 5).
4. **Invalid OSM rings** (bow-ties, unclosed members) must be repaired or skipped per relation. Test: `test_invalid_relation_is_repaired_or_skipped` (Task 5).
5. **Upper-case DBF field names** (`ISO_TER1`, but `x_1`) must be read the same as the lower-case names GBIF's SQL uses. Test: `test_read_rows_lowercases_fields` (Task 2).

### Task 7: Fitting, writing the tree, invariants, and the build

**Files:** Create `scripts/iso/fit.py`, `scripts/iso/write.py`, `scripts/iso/checks.py`, `scripts/iso/build.py`. Test: `scripts/test_iso.py`

**Interfaces:**
- `fit.py`:
  - `MIN_KEEP = 0.10`
  - `territories(parent: str, dual: Mapping[str, str]) -> set[str]`
  - `fit(candidates: Sequence[Candidate], land: BaseGeometry, eez: BaseGeometry, holders: Mapping[str, BaseGeometry]) -> FitResult`
  - `absorb(countries: Countries, codes: Iterable[str], geom: BaseGeometry) -> None`
- `write.py`: `write_tree(iso_dir: Path, countries: Countries, fitted: Mapping[str, FitResult], labels: Mapping[str, str], aliases: Mapping[str, str], config: Config) -> tuple[int, int]`, returning `(features, labels)`.
- `checks.py`: `check_tree(iso_dir: Path, floor_ids: set[str] | None = None) -> list[str]`, returning the problems found.
- `build.py`: `main() -> int`, with flags `--force` and `--workers`.

**Fitting** (keep fraction = area of what is kept ÷ area of the shape; planar degrees are fine). Go through the candidates in priority order: OSM, OSM via Wikidata, Natural Earth, geoBoundaries, derived, placeholder. For each candidate:
1. Clip to `land`, the union of the parent and its territories. If at least `MIN_KEEP` survives, return mode `land`.
2. Otherwise clip to `eez`. If at least `MIN_KEEP` survives, return mode `eez`. The caller then `absorb`s that geometry into the land of each code whose EEZ holds it.
3. A placeholder is kept after any non-empty clip, whatever the fraction.

If no candidate fits, return mode `conflict` with the best candidate unclipped, and `holder` set to the code in `holders` that covers it most.

**Writing:**
- Countries, `YU` and `AN` go to both sets.
- Subdivisions go to `features/` only.
- `aliases` are dual codes, superseded codes, and `TP`→`TL`. They become relative symlinks in `features/`, and also in `eez/features/` when the final target is a country.
- A floor id without any shape (`XZ`) gets its label only.
- `sources.tsv` has the columns `id, resolution, upstream, target, fit, note`.
